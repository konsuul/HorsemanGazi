# Pfert – Käse über dem Bosporus

Ein Canvas-Sidescroller mit automatischem Feuer, Weinwaffen, Bossen und Talentbaum. Direkt im Browser spielbar.

**[Jetzt spielen](https://konsuul.github.io/HorsemanGazi/)** · **[Offline-Version herunterladen](https://github.com/konsuul/HorsemanGazi/releases/latest)**

Für die Offline-Version das Spiel-ZIP entpacken und `Pfert/index.html` öffnen.

## Steuerung

- WASD oder Pfeiltasten bewegen das Pfert.
- Leertaste löst den Wein-Sonderangriff aus, Q den Käserausch.
- Esc öffnet die Pause. Controller werden unterstützt.

## Entwicklung

Ein Push auf `main` startet Tests, Chromium-Prüfung, Deployment und Live-Prüfung. Nach erfolgreicher Veröffentlichung entsteht automatisch ein Release mit Offline-ZIP.
