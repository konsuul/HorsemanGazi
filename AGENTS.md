# Pfert

Ein schlankes, direkt im Browser spielbares Canvas-Spiel. `index.html` öffnen; keine Installation nötig. Änderungen einfach halten.

Bei Implementierungen nur die kleinste für die Aufgabe notwendige Prüfung durchführen. Die README dient zur Auswahl gezielter Tests für betroffene Spielabläufe und konkrete Regressionsrisiken. `node test-all.cjs` und andere vollständige Testläufe nur auf ausdrückliche Anforderung des Nutzers ausführen. Visuelle Browser-Spieltests übernimmt der Nutzer. Getestete Abläufe und etwaige Einschränkungen im Ergebnis nennen.

Bei relevanten Änderungen `ROADMAP.md` beachten und nach Umsetzung und Prüfung aktualisieren. Teilweise erledigte Punkte offen lassen und kurz dokumentieren; neue Anforderungen passend ergänzen.
